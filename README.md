# nameday

A tiny Android app and home screen widget that shows whose name day it is today, based on the Slovak calendar.

- **Widget** shows today's and tomorrow's names, follows Material You colors, and can be resized from 2×2 down to 2×1.
- **App** shows the full year's calendar with today highlighted.
- **Favorites**: long-press a name to star it and see whose name day is coming up next.

## Run

Open the project in Android Studio and hit **Run ▶**. It needs Android 12 or newer.
